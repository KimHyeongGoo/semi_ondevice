Magnetic Fluid Seal Unit Replacement Procedure

Resource Requirements

Item Details
Estimated Time 1 hour
Required Personnel 1 person
Required Tools Handy communication terminal (HCT), Hexagonal wrenches, Wrenches, Phillips screwdriver
Parts / Consumables New magnetic fluid seal unit, Cleanroom wipes (nonwoven), Ethanol/DI water solution, Cleanroom gloves, Plastic sheet
PPE (Personal Protective Equipment) Safety glasses, Safety gloves

Prerequisite Skills / Training

  • Fab safety training
  • Basic tool and instrument use
  • Interlock knowledge and use
  • Controller software use
  • Gas training
  • Mechanical training
  • Knowledge of operating principles and sequence of operations

Maintenance Preparation

  1. 다음 조건을 확인합니다:
    • 실행 중인 레시피 없음
    • 웨이퍼/캐리어 이동 없음
  2. 프로세스 튜브와 배기 라인을 질소로 퍼지합니다.
  3. 적재 구역에서 공기 교환:
    1. 가스 흐름도 패널을 설정하여 밸브를 수동 제어 가능 상태로 만듭니다.
    2. 적재구역 N2 공급라인 밸브 닫기
    3. AIR INV 밸브 누르기
    4. EXH DMPR 밸브 누르기 → 공기 교환 시작
    5. 산소 농도 ≥ 19.5% 확인
    6. N2 공급라인 핸드밸브 닫기
  4. 공기 교환 후 모든 가스 공급 OFF:
    1. 가스 흐름도 패널 스위치 OFF(열린스위치 = 점등)
    2. 가스 라인 모든 핸드밸브 닫기
    3. 위험 가스 밸브 Lock-out / Tag-out
  5. 메인 히터 전원 OFF:
    1. 수동으로 온도 낮춘 후 OFF
    2. 히터 스위치 OFF
  6. 메인 히터가 실온인지 확인 (WAVES/EXCORE 확인)
  7. 보트 엘리베이터 캡 냉각수 공급 차단 (IN→OUT 순서)
  8. HCT 케이블을 가스 박스 단자에 연결
  9. HCT로 보트 엘리베이터를 Tube cart set 위치로 이동
  10. 뒷문 열기
  11. 보트와 받침대 제거
  12. 기계식 일시정지 해제:

    ※ 오직 이 단계 중에만 해제

    1. 도어 프레임 Override 스위치 Pull
    2. BUZZER RESET 누르기
    3. WAVES 알람 상세 화면에서 알람 제거
    4. TX PAUSE / ELV PAUSE 버튼 누르기
  13. HCT로 작업 위치까지 이동
  14. 시스템 완전 종료
  15. Main breaker Lock-out / Tag-out

    16. Magnetic Fluid Seal Unit Removal

  16. 받침대 테이블 제거
    1. 부착 나사 제거 후 분리
    2. 에탄올/DI 물티슈로 클린
  17. 캡 커버 및 열전대 포트 커버 제거(있을 경우)
  18. 커넥터 분리
  19. 안전 팔 제거
  20. 캡 고정 나사 제거(3개)
  21. 플라스틱 시트 설치
  22. 냉각수 파이프 제거

    ※ 누수 시 즉시 Dry → Ethanol/DI 세척

    1. 캡을 약간 들어 올린 상태 유지
    2. 수냉식 파이프 + N₂ 라인 제거
  23. 캡 제거
  24. 자성 유체 씰 유닛, 스페이서, O-ring 제거
  25. 모터, 센서, 타이밍 벨트 제거
  26. 풀리와 키 제거
  27. 씰 유닛 수냉식 라인 제거

    28. Magnetic Fluid Seal Unit Installation

  28. 새 씰 유닛 준비
  29. 수냉식 라인 설치
  30. 풀리 설치
    1. Key 아래 방향으로 설치
    2. 샤프트에 풀리 삽입
    3. Metal washer 설치
    4. 고정
  31. 모터, 센서 및 타이밍 벨트 조립
    1. 육각 나사 3개로 임시 설치
    2. Belt 장력 조정 후 Fix
    3. 센서 충돌 없는지 확인
  32. 씰 유닛 캡 장착
    1. IPA/DI 용액으로 하단 세척
    2. Spacer + New O-ring 설치
    3. 육각나사 4개로 고정
  33. 받침대 테이블 등 역순 조립
  34. 공구/부품 Loose 없음 확인
  35. 뒷문 닫기
  36. Main breaker Lockout/Tagout 해제
  37. System Restart
  38. HCT로 Tube cart set 위치 이동
  39. 뒷문 열기
  40. 보트와 받침대 설치
  41. 뒷문 닫기
  42. 보트 엘리베이터 초기화 → 정상 동작 확인
  43. HCT 케이블 분리
  44. 위험 가스 밸브 Lock-out/Tag-out 해제
